# Mock Booking System
A Mock Hotel Booking System made for a school project which achieved 65/70. Built on python using appJar, SQLite3 and smtplib.
All features are fully Validated and are connected to the program via a fully Normalised Database.

# Features
Login, Sign-up, Staff Logins, Booking Critera Searching, Booking Confirmation via Emails, Booking Editing/Deleting, Edit/Delete Guest Details, Multi Branch Booking.
